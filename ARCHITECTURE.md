# Architecture

> Generated by /map on 2026-03-30

## Overview
InventPro is a unified, real-time inventory and operations control system. It follows a client-server architecture with a React frontend and a Node.js/Express backend, using MongoDB as the primary data store.

## System Diagram
```
[Frontend (React)] <--> [API Gateway / Express Server] <--> [MongoDB]
       |                        |
[AppContext (State)]      [RBAC Middleware]
       |                        |
[ProtectedRoute] <--------> [Auth Controller]
```

## Components

### Frontend Components
- **Layouts**: 
  - `MainLayout`: Wrapper for authenticated pages, includes Sidebar and Header.
- **Pages**:
  - `Dashboard`: Main metrics visualization.
  - `AdminDashboard`: Global system health and metrics.
  - `Inventory`: Product listing and management.
  - `Orders`: Transaction history and creation.
  - `Categories`: Hierarchical organization.
  - `AuditLogs`: Security activity stream.
  - `UserManagement` & `UserApprovals`: Admin personnel control.
- **Context**:
  - `AppContext`: Global state for auth, data (inventory, orders, roles), and UI.

### Backend Components
- **Models**:
  - `User` (`auth.model.js`): Personnel records with roles and status.
  - `AccessRequest`: Onboarding requests.
  - `Product`: Inventory items.
  - `Order`: Transaction records.
  - `Category`: Product groupings.
  - `ActivityLog`: High-fidelity audit logs.
- **Controllers**:
  - `auth`: Handles login, logout, registration, OTP.
  - `admin`: User/role/department management and audit logs.
  - `product`/`category`/`order`/`supplier`: CRUD logic.
- **Routes**:
  - `admin.routes.js`: Protected admin endpoints.
  - `auth.routes.js`: Public and user auth endpoints.
  - `product`/`category`/`order`/`supplier`.routes.js: Operational endpoints.

## Data Flow
1. User interacts with UI components.
2. Components call handlers in `AppContext`.
3. `AppContext` issues axios requests to Node.js API with credentials.
4. API routes process requests through JWT authentication and RBAC middleware.
5. Controllers interact with Mongoose models to query/mutate MongoDB.
6. Actions are logged to the `ActivityLog` collection.
7. Frontend updates state and displays toast notifications.

## Conventions
- **Naming**: CamelCase for components/functions, underscores/hyphens for files based on standard JS conventions.
- **Structure**: MVC pattern in backend, component-based structure in frontend.
- **Styling**: Tailwind CSS for UI, Framer Motion for animations.
- **Dark Luxury**: HSL colors, glassmorphism, neon accents.
